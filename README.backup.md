## 🌟 Flagship Projects

These two best represent what I can build end-to-end today.

### 💬 Chatrr — Real-Time Chat Application
**Full-stack · WebSockets · AI integration**

A complete real-time chat app: users register, log in (JWT), create or join rooms by ID, and message each other instantly — with live online presence, typing indicators, message timestamps, and join/leave notifications. Everything persists in MongoDB, joined rooms are remembered across visits, and an AI bot (`@ChatrrBot`) answers in-room questions using **Google Gemini**.

> **Why it stands out:** it's my most complete full-stack project. It ties together JWT authentication, real-time sockets, REST routes, a three-model MongoDB design, and a polished React UI — the kind of app that trains you on how the frontend and backend really talk to each other.

**Stack:** React · Vite · Node.js · Express · Socket.IO · MongoDB · JWT · Gemini
🔗 [GitHub](https://github.com/Dharani2816/Chattr-Chat-App)

---

### 🌱 Carbon Footprint Calculator
**Full-stack · Data visualisation · AI insights**

A step-by-step calculator that turns home-energy, transport, and diet inputs into a carbon footprint report — complete with an interactive **Chart.js** dashboard, history tracking, benchmarking against Indian averages, JWT-secured accounts, and AI-generated reduction plans (OpenAI / Gemini).

> **Why it stands out:** it shows breadth — a **Tailwind**-styled React frontend, an **Express** backend, **Firebase Firestore** persistence, plus integrating third-party AI APIs and turning raw numbers into visuals.

**Stack:** React · Vite · Tailwind CSS · Chart.js · Node.js · Express · Firebase Firestore · JWT
🔗 [GitHub](https://github.com/Dharani2816/Carbon-footprint-calculator)
